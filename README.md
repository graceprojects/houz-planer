# BROADWAY — планировщик офиса продаж

Личный веб-инструмент для подготовки планировочного задания дизайнеру. Начальный проект — офис 40 × 12 м с высотой зала 6,6 м и вторым ярусом 120 м² (25%).

## Как пользоваться

1. Перетащите карточку мебели на план. Можно нажать карточку, затем место на плане.
2. Потяните предмет за середину, чтобы передвинуть. Угловые ручки меняют размеры, круглая — поворот. Точные значения в миллиметрах — справа.
3. Стена / Витраж — нарисуйте перегородку. Помещение — нарисуйте прямоугольник; стены и дверь появятся сразу. Дверь / Окно — нажмите на нужную стену.
4. Потяните перегородку поперёк: примыкания сохраняются, площади пересчитываются. Концевые точки меняют длину.
5. Нажмите на пол помещения для названия, цвета и пожеланий. Экспликация внизу раскрывается в таблицу.
6. 3D показывает тот же проект. Вращайте мышкой, приближайте колесом, перемещайте правой кнопкой. «Срез стен» показывает интерьер; «Оба этажа» — весь объём.
7. Кнопка «Дизайнеру» открывает печатное задание, SVG, CSV и редактируемый файл. В печати выберите PDF, A3, масштаб 100%.
8. Меню названия проекта: новые проекты, копии, сохранённые варианты и открытие файла .office.json.

Проект сохраняется автоматически в личную базу после входа. Временный черновик в браузере помогает восстановить несохранённые изменения. Файл .office.json — переносимая резервная копия. Конфликт разных окон не перезаписывает чужие изменения: редактор предлагает сохранить копию.

35 типов мебели, 7 комплектов, библиотека готовых назначений помещений. Размеры предметов — стартовые типовые значения, которые можно менять.

## Границы первой версии

Прямоугольные стены и помещения, один первый этаж и один прямоугольный второй ярус в торце. План можно менять в реальном масштабе, но это концептуальное задание, а не BIM-модель и не проверка строительных норм. Площади считаются по внутренним граням стен без дверных порогов; проёмы лестниц исключаются на верхнем ярусе. 3D — схематические предметы заданных размеров. Геометрические предупреждения проверяют границу этажа и пересечение мебели с перегородками.

## Разработка

Node >= 22.13, npm install, npm run dev. Сборка: npm run build. Стек: React, Vinext, Three.js, Cloudflare D1. Конфигурация сайта — .openai/hosting.json. Секретов в исходниках нет.

Миграция D1: drizzle/0000_heavy_mongoose.sql. В production миграции поставляются в архиве сборки через Sites. Локальная база изолирована от production. Владение проектами проверяется на сервере.

Проверка типов: node node_modules/typescript/bin/tsc --noEmit.
Проверки геометрии: ./node_modules/.bin/esbuild tests/geometry.test.ts --bundle --platform=node --format=esm --outfile=.sites-runtime/geometry-test.mjs, затем node .sites-runtime/geometry-test.mjs.

Файлы Blender не изменяются этим приложением.
