# Проверки первой версии · 29.09.2026

- TypeScript: без ошибок; production-сборка Vinext проходит.
- Геометрия: 9 автоматических проверок — исходные площади, сдвиг перегородки, объединение помещений, дверные проёмы, внутренний контур, новое помещение, смена габаритов, недопустимые размеры и диагональные стены.
- API: 7 проверок — вход обязателен, чужой Origin отклоняется, отрицательные размеры отклоняются, создание и обновление сохраняются, устаревшая ревизия и повторный ID не перезаписывают проект.
- В браузере: добавление предмета, перемещение, растяжение 600 → 1100 мм, отмена → 600 мм; сдвиг стены 4000 → 5000 мм пересчитал соседние кабинеты 14,3/15,0 → 18,2/11,1 м².
- Создание прямоугольного помещения мышкой, название, цвет пола и комментарий. Комментарий включён в предпросмотр задания.
- Автосохранение и восстановление после обновления страницы. Тестовые проекты остались только в локальной базе, в production не переносились.
- WebMCP: валидный предмет добавляется, неизвестный предмет отклоняется.
- 3D отрисовывается; обзор адаптирован к пропорциям окна, есть срез стен. Компактное отображение проверено без горизонтального переполнения.
- Печатное задание осмотрено в браузере. PDF создаётся пользователем через системное окно печати; CAD/BIM экспорт не заявлен.
